# 🎯 CS2 道具备忘录 2.0

CS2 道具备忘录。支持在高清地图上标记烟、闪、雷、火点位，附带多图教程与拖拽排序功能。现已适配移动端。

👉 **[在线演示地址](https://zhuzh3378.github.io/CS2-Item-Memo/)**

## 📸 功能亮点
-   🖼️ **结构化图片管理**：站位 / 出手 / 效果三分类，支持拖拽排序调整主图，详情页左右按钮切换 + 全屏查看
-   🔍 **高效检索**：支持按名称搜索、类型筛选、收藏过滤
-   💾 **导入导出**：一键备份/分享你的道具库（JSON 格式和 zip 格式）
-   🤓☝️ **自己添加地图**：在 `manifest` 中添加其他地图素材的路径，烟火雷范围（半径占地图宽度的百分比）就可以自动识别，加入图池（好吧这个我还没测试）

## 🚀 快速开始

### 环境要求

-   **浏览器**：推荐 **Chrome** 或 **Edge**
-   **运行方式**：推荐使用 [在线演示地址](https://zhuzh3378.github.io/CS2-Item-Memo/) 或本地服务器（HTTPS 环境）。直接双击打开 HTML 文件（`file://` 协议）可能导致存储功能不可用
-   **也可以在局域网运行 [工具 LAN-Server](https://github.com/zhuzh3378/LAN-Server)
